# イベント台帳接続の実地通し確認結果

2026年9月4日、Google認証後の本人限定テスト環境で、イベント募集から申込み、キャンセル、管理者による受付再開までを通して確認した。本記録は検証結果のみを残すものであり、アプリ本体の変更や本番公開を行うものではない。

## 確認結果

| 確認項目 | 結果 |
| --- | --- |
| イベントと申込みの保存 | テスト用のイベント台帳にイベント1件、テスト用の申込台帳に申込み1件を保存できた |
| 再送時の重複防止 | 同じ内容を再送しても、イベント・申込みともに重複して増えなかった |
| 開き直した後の保持 | 画面を開き直しても、ポスター、日時、会場、定員を保持していた |
| キャンセルと受付再開 | 申込行を削除せずキャンセル履歴を残し、管理者の明示的な操作で受付を再開できた |
| 受付停止中のほかの機能 | 申込みの受付を停止している間も、水曜会ポータルと花図鑑を開くことができた |
| テスト終了時の状態 | 最後にテストイベントを「締切」に戻し、申込みできない状態にした |

Google台帳を読み戻し、画面表示だけでなく、保存件数と最終状態も確認した。

## 確認範囲

今回確認したのは、本人限定のテスト環境とテスト専用台帳を使った通し試験である。一般参加者向けの本番運用、一般参加者と管理者の権限分離、本番用イベント台帳への接続が完了したという意味ではない。

この確認と記録では、次のものを変更していない。

- アプリ本体
- 本番公開中の画面
- 正式受付台帳
- 既存スタンプ
- 本番データ

個人名、台帳ID、非公開画像ID、秘密の接続情報は本記録に含めない。

## 次に確認すること

本番公開を急がず、本番用接続先の分離、一般参加者と管理者の権限分離、申込機能だけを停止できる操作、実際のイベント内容・定員・申込区分・ポスターを確認する。公開前には確認結果と公開候補を提示し、承認を受けてから進める。
