# ポスター表示の確定と管理側見本

悦子さんが画像入り見本を「ポスター掲載の仕組みとして確定してよい」と承認。縮小・全体拡大・文字拡大・閉じる・暗い背景の表示方法を確定し、approved-poster-v2へ画像・コード・HTML・サーバーファイルを保存、コピー元とのハッシュ一致を確認した。

「画像の表示確認用です。9/26の案内ポスターではありません。」は9/26の正式ポスターへの差し替え時に外す。承認は表示方式に対するもので、6月の表紙を9/26の正式告知として扱う承認ではない。文字量・縦横比が異なる将来のポスターの読みやすさまで保証しない。

## 管理側の未公開見本

URL: http://127.0.0.1:4196/poster-admin.html

1. JPEG・PNG・WebPの画像を選ぶ（10MBまで）。
2. 画像・ファイル名・寸法を確認する。この時点では参加者側に反映しない。
3. 「見本に反映して確認する」で参加者側のカード画像と拡大画像を差し替える。
4. 上部の「管理側の見本」「参加者側の見本」で往復する。

画像はブラウザ内の一時URLでのみ表示し、アップロード・Google台帳保存・端末内の永続保存は行わない。ページ再読込みで元に戻る。本番では永続的な画像保存先と管理者認証が必要であり、今回の管理画面は認証済みの本番管理機能ではない。

元の参加者側index.htmlは変更せず、別のposter-admin.htmlを生成。既存の承認済み画像入り見本とindex.htmlのハッシュ一致も確認。管理側見本のスクリプト構文、保存・通信処理の混入がないこと、HTTP 200、画像選択欄と反映ボタンの出力を確認した。操作感は悦子さんの確認対象。

本番ポータル・花図鑑・Google台帳・スタンプ・番号・GitHubに変更なし。管理側見本への承認前に本体には組み込まない。
