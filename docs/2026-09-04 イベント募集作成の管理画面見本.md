# イベント募集作成の管理画面見本

URL: http://127.0.0.1:4196/event-editor.html

管理側のポスター差し替え見本を基に、イベント名・開催日・開始時刻・会場・任意の指導棋士・イベント全体の定員を入力する別の未公開見本を作成した。

## 操作

1. イベント情報を入力。初期値は提示済み9/26の情報、定員20名は仮値と明記。
2. ポスターを選ぶ。現在の画像のままでも確認できる。
3. 「募集内容を確認する」で日時・会場・画像・定員を確認する。
4. 「この内容で受付開始〈見本〉」で参加者側のカード・詳細・申込確認画面へ情報を反映する。
5. 管理側へ戻って修正できる。画像選択や入力だけでは参加者側の表示を変更しない。

残席はテスト表示であり、申込者0名を前提に設定した定員を表示する。Google台帳から取得する本番の残席ではない。申込完了画面の見本を押しても人数や予約を保存しない。

入力名・会場は空白のみを許可せず、日付・時刻・正の整数の定員を確認する。文字列の反映にはtextContentを使い、HTMLとして実行しない。画像の形式・サイズ・読み込み確認は既存の管理側見本と同じ。スクリプト構文と保存・通信処理の混入なしを確認し、HTTP 200と入力・確認・開始ボタンの出力を確認した。実際の操作感はユーザーの見本確認対象。

この見本はブラウザ内の一時表示だけ。永続保存、管理者本人確認、募集開始日時の本番判定は未実装。本番接続・公開・Google台帳・スタンプ・番号・GitHubへの変更は行っていない。承認済みの参加者側とポスター差し替え見本のHTMLは上書きせず、event-editor.htmlを別途生成した。

今後の追加候補として、同じイベント情報からX・LINEへ貼り付ける告知文を作る機能を記録。今回は実装も外部送信もしていない。
