# コスモスの参加スタンプが開かない不具合

悦子さんより、先生の花はタップできるが参加スタンプはタップできないと報告。参加2個はGoogle台帳で既に反映済み。

花図鑑のコスモスがshowParticipationStampEntryから非表示の古いparticipation-stamp欄を強調するだけになっていた。先生の花は詳細を表示するため症状が異なった。

コスモスのクリックを既存のopenParticipationStartSheetへ接続。地図の「参加する」と同じ既存画面で、現在の花と参加回数を確認できる。新しいデザインや記録変更はなし。script.jsのキャッシュ用バージョンを更新。

ローカル実ブラウザで花図鑑→コスモスをクリックし「水曜会参加の入口」「参加スタンプ」「コスモス」「0/10回 あと10回」が表示されることを確認。検証用ブラウザは記録なしのため0回。本人の記録には触れていない。構文チェック成功。

GitHub commit 534c3ba8b112fc822c178274c9ecd96ee70f72b4。本人には修正版を通常Safariで開き、花図鑑→コスモスから2/10回を確認するよう案内。

本人確認完了：悦子さんから「2個ついてます」と写真を受領。参加スタンプ画面にコスモス、花記録番号40471839、「2/10回 あと8回」、サイトで名前登録済みの案内が表示されている。既に確認済みのGoogle台帳の「反映済み」と合わせ、悦子さんの参加2個の端末保存・表示・台帳受領確認が完了。他の9名の端末反映を示すものではない。
