### 2.4 「第1段階への影響」と「決定期限」の読み方

「第1段階への影響」は、未決定事項があるため停止する範囲を示す。優先度の高さと停止範囲の広さは同じものではない。

| 表記 | 意味 |
|---|---|
| 全体を停止 | 第1段階全体を進めない |
| 該当機能だけ停止 | その項目に直接関係する機能の実装・試験を保留する |
| 画面の完了判定だけ停止 | サーバー側など分離できる実装は進められるが、利用者画面を完成扱いにしない |
| 特定試験だけ保留 | 基礎実装は進められるが、その項目に対応する試験を実施済み・合格扱いにしない |
| 実装を止めない | 第1段階の実装・試験を止めず、記載した時期までに必要な判断または将来検討を行う |

「決定期限」の「決定済み」は後続の正式文書ですでに承認済みであることを示す。「実装開始前」「該当機能の実装前」「結合試験前」「実利用開始前」「第1段階後でも可」は、未決定事項をいつまでに決める必要があるかを示す。
