# 水曜会ポータル 画面見本（2026年9月3日）

悦子さんの確認と承認を受けた、水曜会ポータル全体の画面見本です。
これは将来の制作に使う設計資料であり、現在公開中の「水曜会 花記録」アプリにはまだ組み込まれていません。

## 見られる内容

- 次回の定例会と、折りたたんで確認できる今月3～5回分の日程
- イベントのお知らせ、ポスター画像、転送、参加申込みの画面見本
- 水曜会リーグの入口、本人確認、結果送信、順位表、参加者別成績
- 先生からのお知らせ、2行コメント、掲載期間、管理者用編集画面
- 先生本人だけが見られる「一局のご縁帳」と過去の指導碁記録
- 管理者が対局者名、手合い、アマ勝ち・アマ負け、その日の記録を入力する画面
- 指導碁を9局以上でも必要なだけ追加できる入力方法
- 現在の花記録アプリへ移動する入口の見本
- 既存の8桁番号を使って「今までの花記録をつなぐ」初回連携の画面見本
- 8桁番号が分からない方、スマホを持っていない方への案内

画面内の名前、会員番号、成績、日付、場所などはすべて見本用です。本人確認、権限管理、データ保存はまだ本番へ接続していません。

## 会員と花記録の方針

- 現在の花記録は、既存のブラウザ内記録を守るためGitHub Pagesの同じURLで開く
- 既存参加者は、花記録の8桁番号とポータル会員情報を初回だけ結び付ける
- 連携確認には、管理者が発行する15分間・1回限りのQRを使う想定
- QRには氏名、8桁番号、権限そのものを直接入れない
- 水曜会参加QRとリーグ参加申請QRは分けられるが、リーグ権限は管理者確認後に付与する
- 途中からリーグへ参加する方は、同じ会員番号のまま管理者が権限を追加する
- スマホを持っていない方は、管理者が登録できる形にする

## 確認方法

最も簡単な確認方法は、このフォルダーでローカルHTTPサーバーを起動して `preview.html` を開くことです。

```powershell
npm install
npm run dev
```
